# bicantor

`bicantor encode tree "(()(()))()"` - закодировать дерево в номер

`bicantor decode tree 9` - раскодировать дерево из его номера

Также для веселья вместо tree можно написать list (для кодировки/раскодировки списка целых чисел)
или pair (пара целых чисел).

Крейт [argh](https://crates.io/crates/argh) - просто золото, предоставил чудесную справку,
доступную через help. Очень рекомендую попробовать его в ваших проектах.
